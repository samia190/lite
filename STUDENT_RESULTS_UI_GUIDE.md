## Color Coding

### Buttons & Badges:
- 🟣 **Purple Gradient:** Manual entry button, download report
- 🔴 **Pink Gradient:** PDF upload button, view PDF
- 🔵 **Blue Badge:** CBC curriculum
- 🟠 **Orange Badge:** 8-4-4 curriculum
- 🔴 **Pink Badge:** PDF type
- 🟢 **Green Badge:** Manual type
- 🟢 **Green Status:** Published
- 🟡 **Yellow Status:** Draft

### Performance Indicators:
- 🟢 **Green:** Strong subjects, improved performance
- 🟠 **Orange:** Weak subjects, areas to focus
- 🔵 **Blue:** Information, recommendations
- 🔴 **Red:** Declined performance (if severe)
- ⚫ **Gray:** Maintained/neutral

## Download Options

### If Admin Uploaded PDF:
```
[📄 View Official PDF]     <- Opens PDF in new tab
```

### If Admin Entered Subjects:
```
[📥 Download Detailed Report]  <- Generates PDF with jsPDF
```

### If Both Exist (Hybrid):
```
[📄 View Official PDF] [📥 Download Detailed Report]
```

Both buttons available side-by-side!
