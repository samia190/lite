## 🔐 How to Access Results

### Method 1: Email Login
1. Go to login page
2. Enter email (e.g., `ibrahim.koise@student.kangaru.ac.ke`)
3. Enter password: `kangaru2025!`
4. Click Login
5. Navigate to "My Results"

### Method 2: Student Verification (No Login Required)
1. Go to "Student Verification" page
2. Enter Full Name (e.g., `IBRAHIM S. KOISE`)
3. Enter Admission Number (e.g., `64121`)
4. Enter Date of Birth (e.g., `2008-05-15` or select from calendar)
5. Click "View Results"
6. Results displayed instantly without logging in

## ✅ How to Run the Seed Script

```bash
cd kangarubackend
node scripts/seedStudentResults2025.js
```

- Create 5 student user accounts
- Upload their KCSE 2025 results
- Calculate positions and mean grades
- Display login credentials
